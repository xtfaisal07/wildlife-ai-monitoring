# 🌿 WILDEYE AI – Wildlife Monitoring System

An AI-powered wildlife monitoring system that detects animals and human presence using deep learning (YOLOv8).
Designed for forest surveillance, anti-poaching monitoring, and biodiversity conservation.

---

## 🚀 Features

* 🧠 Real-time object detection using YOLOv8
* 🎥 Live camera monitoring
* 🖼️ Image upload detection
* 📹 Video analysis with frame processing
* 🚨 Human (poacher) detection alert
* 📊 Interactive dashboard with analytics
* 💾 Detection logs stored in SQLite database

---

## 🧩 System Architecture

Input (Camera / Image / Video)
→ YOLOv8 Model
→ Detection Engine
→ Alert System
→ Dashboard & Storage

---

## 🛠️ Tech Stack

* **Backend:** Python, Flask
* **AI Model:** YOLOv8 (Ultralytics)
* **Computer Vision:** OpenCV
* **Frontend:** HTML, CSS, JavaScript
* **Database:** SQLite
* **Deployment:** Render

---

## 📊 Dashboard

* Detection logs stored and displayed
* Bar & Pie charts for analytics
* Real-time detection insights

## ⚙️ Installation (Local Setup)

```bash
git clone https://github.com/YOUR_USERNAME/wildlife-ai-monitoring.git
cd wildlife-ai-monitoring
pip install -r requirements.txt
python app.py
```

Open browser:

```
http://127.0.0.1:5000
```

## 🌐 Deployment

Deployed using **Render (Free Tier)**
